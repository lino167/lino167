### 🥇 1. [Kraflo-CMMS](https://github.com/lino167/Kraflo-CMMS) — *Sistema de Gestão de Manutenção Industrial (Ops-Tech)*

> Aplicação web de porte corporativo concebida a partir de necessidades reais de chão de fábrica: gestão completa de ordens de serviço, controle de histórico de falhas, manutenção preventiva/corretiva e assistência orientada por IA.

**Deploy da Aplicação:** [kraflo.vercel.app](https://kraflo.vercel.app/) *(cadastro gratuito necessário)*

| Camada Técnica | Implementação |
|---|---|
| **Arquitetura Front-End** | React 18 + TypeScript + Vite |
| **Design System & UI** | Tailwind CSS + Radix UI + Framer Motion |
| **Backend & Banco** | Supabase (PostgreSQL, Triggers, RLS, Edge Functions, Auth) |
| **Cache & Estado Assíncrono** | TanStack React Query v5 |
| **Validação de Formulários** | React Hook Form + Zod (Strict typing) |
| **Inteligência & Relatórios** | Gráficos com Recharts + Exportação com jsPDF / AutoTable |
| **Qualidade & Testes** | Vitest + Testing Library |
