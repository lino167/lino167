### 🔧 [Kraflo-CMMS](https://github.com/lino167/Kraflo-CMMS) — *Projeto Principal em Andamento*

> Sistema de Gerenciamento de Manutenção Computadorizado (CMMS) construído para resolver problemas reais de gestão de ativos e ordens de serviço na indústria.

**Deploy:** [kraflo.vercel.app](https://kraflo.vercel.app/) *(cadastro gratuito necessário)*

| Camada | Stack / Ferramenta |
|---|---|
| **Frontend** | React 18 + TypeScript + Vite |

| **Gerenciamento de Estado** | React Query (@tanstack/react-query) |
