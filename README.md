## 🚀 Ecossistemas & Projetos em Destaque

### 🏭 1. [Kraflo-CMMS](https://github.com/lino167/Kraflo-CMMS) + [bot-os-kraflo](https://github.com/lino167/bot-os-kraflo) — *Ecossistema de Gestão de Manutenção Industrial*

> Plataforma SaaS corporativa nascida de necessidades reais do chão de fábrica: gestão completa de Ordens de Serviço (OS), controle de ativos, cálculo de indicadores (MTTR/MTBF), abertura de chamados em campo via Telegram e assistente técnico de IA com busca semântica (RAG) em manuais PDF.

- **Deploy em Produção:** [kraflo-cmms.vercel.app](https://kraflo-cmms.vercel.app)
- **Destaques de Engenharia:**
  - **Front-End:** React 18 + TypeScript + Vite + Tailwind CSS + Shadcn/UI + TanStack Query v5 + React Hook Form & Zod.
  - **Back-End & Segurança:** Supabase PostgreSQL com **Row Level Security (RLS)** multi-empresa, Triggers PL/pgSQL e Edge Functions (Deno).
  - **Omnichannel de Campo (`bot-os-kraflo`):** Bot em Python integrado ao Supabase Storage permitindo que técnicos abram OS, anexem fotos da avaria e gerem relatórios PDF/CSV direto pelo celular.
